# My PaperMC Plugin

A plugin for a private Minecraft server — built for fun, silly mechanics, and some QoL improvements.  
Feel free to use and modify it for your own server.

## 📦 Installation
1. Download the latest release (or dev build).
2. Place the `.jar` file into your server’s `plugins/` folder.
3. Restart or reload the server.
4. Edit `config.yml` as needed.
